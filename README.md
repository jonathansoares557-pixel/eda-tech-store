# EDA Tech Store

Análise exploratória de vendas a partir do `vendas.csv`.

- `analise_vendas.py` / `analise_vendas.ipynb`: análise (registros, receita total, Eletrônicos, produto mais vendido, região com maior valor, gráficos, tabela dinâmica e relatório Excel).
- `gerar_vendas.py`: gera um `vendas.csv` de exemplo (opcional).

## Como executar
```
pip install pandas matplotlib openpyxl
python analise_vendas.py
```
